# Blood Test AI

## Educational Clinical Blood Test Analysis System

Blood Test AI is a rule-based educational system designed to analyse laboratory blood-test parameters and provide structured findings, suggestions, severity indicators, and clinical explanations.

### Features

- Patient information entry
- Comprehensive blood-test parameter input
- Male and female reference ranges
- SI laboratory units
- Automated rule-based analysis
- Anaemia classification
- Iron deficiency assessment
- B12/folate deficiency assessment
- Microcytic and macrocytic pattern detection
- Infection/inflammation indicators
- White-cell abnormalities
- Platelet abnormalities
- Haematological pattern detection
- Blood-film morphology guidance
- Clinical explanation section
- Structured results
- Patient JSON export
- Printable report
- Educational clinical reasoning

### Important Disclaimer

This application is intended strictly for educational and demonstration purposes.

It is not a medical device and must not be used as a substitute for professional medical advice, diagnosis, treatment, laboratory interpretation, or emergency clinical decision-making.

All findings require appropriate professional review and confirmation using validated laboratory methods and clinical information.

### Technology

- HTML5
- CSS3
- JavaScript
- Client-side rule-based analysis
- No server required
